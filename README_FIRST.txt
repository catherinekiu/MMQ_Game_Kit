IMPORTANT CONCEPT CONVENTION
For a × b, MMQ uses a groups/rows with b items in each group/row.
Example: 4 × 3 corresponds to 3 + 3 + 3 + 3 and an array of 4 rows with 3 items per row.

The Array Model practice keeps the visual array hidden until the pupil selects Hint.
