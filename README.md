# MathArcade: Multiplication Quest! (MMQ!)

MMQ! is a bilingual browser-based mathematics game kit for primary pupils.

## Languages
- English (UK)
- Simplified Chinese

## Learning path
1. Motivation
2. Cognitive Support
3. Procedural Practice
4. Fluency Reinforcement
5. Fluency Competency

## Activities
- Introduction Song
- Array Model
- Chair Arrangement
- Popubbles!
- Catch Me!
- Multiplication Board

## Use locally
Open `START_HERE.html`.

## Use with GitHub Pages
This repository includes `index.html`, so GitHub Pages can open MMQ! directly
from the public Pages URL.

## Technical notes
- Static HTML, CSS and JavaScript
- No server required
- Relative asset paths are GitHub Pages compatible
- The introduction video is compressed in this GitHub-ready package for web hosting
